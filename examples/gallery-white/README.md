# Gallery White example: Lumen One

A one-page launch site for a fictional desk lamp, built with Preset L "Gallery
White". It is plain HTML and CSS with no dependencies. The two studio-light
plates were generated by the skill.

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## What it shows

- White and near-white bands, with one black "stage" band for the second product
- System fonts at display scale, one blue accent, pill buttons, 28 px tiles
- Separation by tone only: no shadows and no borders on tiles
- A glass nav and a sticky product bar; both turn dark over the stage
- Studio light behind each product, generated from the page's own colours

## How the plates were made

From the repository root:

```bash
GEN=skills/fantastic-ui/scripts/gen_atmosphere.py
python3 $GEN plate --palette '#000000,#141416,#2a2a2e,#0062c4,#3d9bff' --page '#000000' \
  --style studio --seed 1 --size 1600x900 --focus 0.5,0.62 --intensity 1.0 --max-kb 30 \
  --slot 1440x620 --scrim none --fit cover --out examples/gallery-white/stage.webp
python3 $GEN plate --palette '#ffffff,#f4f4f6,#d5d5da,#0062c4,#3d9bff' --page '#ffffff' \
  --style studio --seed 1 --size 1600x900 --focus 0.5,0.62 --intensity 1.0 --max-kb 30 \
  --slot 1440x620 --scrim none --fit cover --out examples/gallery-white/ground.webp
```

They come out at 6.3 KB (stage) and 4.7 KB (light).

## Checking it

Serve the folder, then, from a project with `playwright` and `@axe-core/playwright` installed:

```bash
node skills/fantastic-ui/scripts/verify-preset.mjs --preset L --url http://localhost:8000/index.html
```

Measured on this page: all 13 preset gates pass, and axe (WCAG 2.2 AA tags) reports no critical or serious violations.
`plate-check.js` puts the plates at 50.6 / 20.8 (light) and 87.0 / 44.6 (stage)
at 1440 px, and 40.8 / 12.3 and 76.6 / 26.9 at 375 px. Each pair is the
percentage of covered pixels at least 1.1:1 and 1.3:1 from the page. The
floors are 8 and 1.

Lumen One is invented for this demo. The page uses no real brand's name,
marks, product images or exact colour values.
